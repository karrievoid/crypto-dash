# Crypto Dash

A small React dashboard that shows live cryptocurrency prices from a public API.
Built while following Brad Traversy's Modern React From The Beginning course.

**Live site:** https://crypto-dash-ivory-nine.vercel.app

## What I practised
- Fetching data with useEffect and handling loading and error states
- Passing data between components with props
- Search, sort and limit controls, and a coin details page with a price chart

## Run it locally
```
npm install
npm run dev
```
